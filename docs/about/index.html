This Australian Filmography project is primarily an exercise in leveraging open data and presenting it in a form which encourages interaction and exploration.

The corpus is derived from three authoritative texts on Australian Film, but all actual data is sourced from Wikidata.

This also makes this a community project - if you see something which is incorrect, edit it on Wikidata and the changes will flow to this site.

This web application was built using Python, Flask and d3.js.

Issues can be logged at the project repository.
